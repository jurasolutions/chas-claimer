## 6. Defects

### D03 Minor: Who pays on a held, unsent claim cuts a sent claim's share

**Repro**

1. Take visit D04b. Approve and send CHAS ($620) and Flexi ($400) so both are submitted or paid.
2. Re-import D04b with every treatment fee halved (the bill becomes $708.50).
3. Open Meridian 762e4e8c, which is now held by `sent_claims_exceed_fee`.

**Expected:** the sent claims keep their amounts in Who pays (CHAS $620, Flexi $400), or the panel
says the bill is over-claimed by the sent claims.

**Actual:** Who pays reads CHAS $620.00, **Flexi-MediSave $88.50**, Meridian $0.00, Patient $0.00. On
the same page, "Other claims for this visit" shows Flexi $400.00 Paid, and the finding says $1,020.00
was sent. The two panels contradict each other (`qa04-sefee-meridian.png`).

**Severity:** Minor. It shows only in the held state, where nothing can be approved or sent, and the
blocking finding states the right figures.

**Cause:** `claimDetail` in `server/services/claims.ts` (around line 606) uses `frozenVisitSplit` only
for a sent claim. For an unsent claim it calls `splitVisit` → `splitAcross`
(`src/domain/claims/build.ts` around line 578), which caps each claim at min(claimed, what is left) in
waterfall order. When sent claims exceed the new bill, the later sent claim is cut to the remainder.

**Fix suggestion:** in `splitAcross`, take sent claims at their claimed amount first and let only open
claims and the patient share what is left. Or, when the visit carries `sent_claims_exceed_fee`, show
the sent amounts with a line saying they exceed the bill.

**Failing test (red step).** I ran it as `server/services/qa04-held-claim-who-pays.test.ts` and then
removed it, so `git status` stays clean. A copy is in the session scratchpad as
`qa4/red/qa04-held-claim-who-pays.test.ts`. It fails with `AssertionError: expected 8800 to be 40000`
(1 failed). The fixture fee halves to $708.00, so the test gets 8800 where the browser showed 8850.

```ts
import { describe, expect, it } from "vitest";
import { cents } from "../../src/domain/money";
import type { Actor } from "../../src/domain/types";
import { REVIEWER } from "../../tests/helpers/env";
import { configuredDesk, CONNECTOR_ACTOR, OFFICER_ACTOR, visitByKey } from "../../tests/helpers/fixtures";
import * as claims from "../repo/claims";
import { act, claimDetail } from "./claims";
import { importVisits } from "./imports";

const REVIEWER_ACTOR: Actor = { kind: "person", email: REVIEWER, roles: ["officer", "reviewer"] };

async function schemeClaim(db: D1Database, scheme: string) {
  const claim = (await claims.forVisit(db, "SC-D04b")).find((c) => c.scheme === scheme);
  if (!claim) throw new Error(`no ${scheme} claim for SC-D04b`);
  return claim;
}

async function submitted(deps: Parameters<typeof act>[0], db: D1Database, scheme: string, portalReference: string) {
  const claim = await schemeClaim(db, scheme);
  expect(await act(deps, claim.id, { kind: "approve" }, claim.version, REVIEWER_ACTOR)).toMatchObject({ ok: true });
  const approved = await schemeClaim(db, scheme);
  expect(await act(deps, claim.id, { kind: "submit", portalReference }, approved.version, OFFICER_ACTOR)).toMatchObject({ ok: true });
  return schemeClaim(db, scheme);
}

describe("QA 04 D03: Who pays on a claim held by sent_claims_exceed_fee", () => {
  it("shows each sent claim at the amount it was sent for, not cut to what the lower fee leaves", async () => {
    const { db, deps } = await configuredDesk();
    const v = visitByKey("SC-D04b");
    await importVisits(deps, { source: "connector", visits: [v] }, CONNECTOR_ACTOR);
    const chas = await submitted(deps, db, "chas", "QA4-0001");
    const flexi = await submitted(deps, db, "medisave_flexi", "QA4-0002");

    const halved = { ...v, treatments: v.treatments.map((t) => ({ ...t, feeCents: cents(Math.round(t.feeCents / 2)) })) };
    await importVisits(deps, { source: "connector", visits: [halved] }, CONNECTOR_ACTOR);

    const held = await schemeClaim(db, "insurance");
    const detail = (await claimDetail(deps, held.id, OFFICER_ACTOR))!;
    const shareOf = (id: string) => detail.split.segments.find((s) => s.claimId === id)?.cents;
    expect(shareOf(chas.id)).toBe(62000);
    expect(shareOf(flexi.id)).toBe(40000); // actual: 8800 here (fixture fee 70800); 8850 in the browser run
  });
});
```
